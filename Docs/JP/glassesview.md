# GlassesView ガイド

GlassesView は、現在の曲、再生進行、スクロール可能な操作項目を表示します。Spotify 認証と詳細設定は先に[スマートフォン WebView](./webview.md)で完了してください。

![H 非表示項目を含む GlassesView の実際のレンダリング](./assets/glasses-display-content.png)

この画像は Even Hub simulator の Glasses Display による実際のレンダリングであり、実機メガネの写真ではありません。

## 開始前の確認

1. スマートフォン WebView が **接続済み** であること。
2. Spotify にオンラインの再生デバイスが 1 台以上あること。
3. 曲を再生し、スマートフォンに曲名と進行状況が表示されること。
4. グラスで Even Hub Spotify Console を開くこと。

## 基本ジェスチャー

| ジェスチャー | 動作 |
| --- | --- |
| 左右にスクロール | 表示中は選択中の操作項目を移動し、スクロール反転が有効な場合は方向が逆になる。非表示中の最初のスクロールは表示を復元して直ちに終了する |
| シングルクリック | 表示中は選択中の操作を実行する。非表示中の最初のクリックは表示を復元して直ちに終了する |
| ダブルクリック | Even システムの終了確認を開く。GlassesView の非表示や復元は行わない |

app を前面に戻しても、非表示の画面は強制的に再表示されません。画面が空の場合は、クリックまたは左右いずれかに 1 回スクロールして復元します。この復帰操作では、再生、曲送り、リスト選択、デバイス切替、フォーカス移動を行いません。非表示中のダブルクリックでもシステム終了確認が開きます。

## 再生操作

既定の順序は次のとおりです。

```text
PL → S/S+ → 前の曲 → 再生/一時停止 → 次の曲 → リピート → H → DV
```

- `PL`：プレイリストを開く。
- `S` / `S+`：シャッフルのオフ/オン。
- 前の曲、再生/一時停止、次の曲：現在の Spotify 再生デバイスを操作。
- リピート：オフ、1 曲、全曲を切り替える。
- `H`：GlassesView を非表示にする。終了ではなく、`shutDownPageContainer()` や Spotify API を呼び出さない。
- `DV`：Spotify デバイスを開き、再生先を切り替える。

クリック後は状態が更新されてから次の操作を行ってください。進行表示はローカルで 1 秒ごとに進み、定期的に Spotify と再同期するため、一時的なずれは正常です。

## プレイリスト

1. `PL` までスクロールしてシングルクリックします。
2. リストの先頭項目で再生中画面へ戻れます。
3. **Liked Songs** またはスマートフォンで設定したプレイリストを選びます。
4. シングルクリックすると再生を開始し、メイン画面へ戻ります。

**Liked Songs** は現在シャッフルで再生を開始します。選択できる一覧は、スマートフォン WebView のプレイリスト枠で設定します。

## 再生デバイスを切り替える

1. `DV` までスクロールしてシングルクリックします。
2. リストの先頭項目で再生中画面へ戻れます。
3. オンラインの Spotify デバイスを選び、シングルクリックします。
4. 切替の完了を待ちます。

一覧が空の場合は、Spotify 公式のスマートフォンまたはデスクトップアプリで曲を再生してから、スマートフォン WebView の接続を更新してください。

## 表示と自動非表示

次のグラス設定はスマートフォン WebView から変更します。

- 進行表示、枠線、文字レイアウト。
- アルバム画像の大きさと透明度。
- 操作アイコンと左右スクロールの方向。
- 自動非表示の有効化と待ち時間。

自動非表示を有効にした場合だけ、無操作時に画面が隠れます。自動非表示と `H` による手動非表示は同じ方法で復元します。最初のクリックまたは左右いずれかへのスクロールは表示を復元して直ちに終了します。ダブルクリックは復元ではなく、Even システムの終了確認を開きます。

## よくある問題

- **表示はあるが操作できない**：Remote モードと Premium アカウントを使用してください。
- **進行表示が更新されない**：スマートフォンの接続、self-host サービス、Tailscale を確認してください。
- **選択が反対方向へ動く**：スクロール反転を切り替えてください。
- **画面が消えた**：自動非表示の可能性があります。クリックまたは左右いずれかに 1 回スクロールしてください。復帰操作では現在の操作項目を実行しません。
- **app を終了したい**：ダブルクリックし、Even システムの確認画面で選択してください。`H` は表示を隠すだけです。
- **曲またはデバイス一覧が空**：先に Spotify 公式クライアントで有効な再生デバイスを作ってください。

認証やネットワークの問題は[トラブルシューティング](./troubleshooting.md)を参照してください。
