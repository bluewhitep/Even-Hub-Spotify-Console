# 使用方法

UI は 2 つに分かれます。スマートフォン WebView はログイン・接続・再生・設定を担当し、GlassesView はすぐ確認できる状態表示とジェスチャー操作を担当します。

## スマートフォン WebView

[スマートフォン WebView ガイド](./webview.md)では次を説明します。

- 初回ログインと接続の順序
- Embed と Remote モード
- 再生操作とプレイリスト
- 表示設定、設定の書き出し、セッション消去
- 接続の復旧

## GlassesView

[GlassesView ガイド](./glassesview.md)では次を説明します。

- 左右スクロール、シングルクリック、ダブルクリック
- 再生、シャッフル、リピート、プレイリスト、デバイス切替
- 自動非表示と復旧
- 空の一覧や操作不能の確認項目

## 推奨する順序

1. スマートフォンで Spotify のログインと接続を完了します。
2. Spotify 公式クライアントで曲を再生し、有効なデバイスを作ります。
3. スマートフォンで Remote モードとプレイリストを設定します。
4. GlassesView を開き、表示とジェスチャーを確認します。

インストールが未完了なら[ローカルデプロイ](./deployment.md)から始めてください。エラーがある場合は[トラブルシューティング](./troubleshooting.md)を参照してください。
