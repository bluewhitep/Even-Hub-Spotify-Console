- you open the page in the real Even app
- glasses WebView needs to reach the same HTTPS origin
- the local self-host server handles Spotify OAuth callback and token storage
- Spotify callback returns to `/api/auth/callback`

## Start

Recommended command from project root:

```bash
./scripts/start-self-host.sh
```

Manual backend path:

```bash
cd app
npm run host:device
```

`host:device` sets:

```text
VITE_SPOTIFY_AUTH_MODE=server
```

For detailed steps, see [Self-Hosting Details](./self-hosting.md).

## Spotify Redirect URI

Real-device self-host server mode uses:

```text
https://<device>.<tailnet>.ts.net/api/auth/callback
```

Do not use:

```text
https://<device>.<tailnet>.ts.net/callback.html
```

For the full form fields, see [Spotify Developer Dashboard Setup](./spotify-dashboard.md).

## Local Package and HTTPS

In the packaged device flow:

1. start the local server and Tailscale proxy;
2. run `npm run pack:ehpk` to generate an `.ehpk`;
3. transfer the `.ehpk` to the phone and open it locally with Even Realities App / Even Hub.

Any QR generated by the startup script is only for loading an unpackaged development page from the computer. It is not a release installation or device-pairing step.

For manual HTTPS exposure, see [Tailscale HTTPS Guide](./tailscale.md).

## Verification

Before connecting, confirm:

- `self-host.config.json` contains your `spotifyClientId`
- `serviceOrigin` is the final HTTPS origin
- `allowedTailscaleUsers` contains the exact Tailscale login of the phone's requesting user, not a device hostname
- `allowedOrigins` contains `"http://127.0.0.1:*"` for the packaged WebView's installation-assigned local port
- Spotify Dashboard has `https://<device>.<tailnet>.ts.net/api/auth/callback`
- the displayed server domain is `<device>.<tailnet>.ts.net`
- select `Input server domain`, fill `Server API Origin` in Settings, then select `Save and connect server`; `https://` may be omitted
- the phone page shows `Service Origin` as `https://<device>.<tailnet>.ts.net`
- the phone page shows `Redirect URI` as `https://<device>.<tailnet>.ts.net/api/auth/callback`
- `Settings` / diagnostics `Effective Redirect URI` ends with `/api/auth/callback`

On a real device, select `Login Spotify` and sign in with your Spotify account rather than Google quick login. Return to or reopen the plugin after authorization, save and connect the server origin, then select `Connect Spotify`.

After connecting, see the separate [phone WebView](./webview.md) and [GlassesView](./glassesview.md) guides.
